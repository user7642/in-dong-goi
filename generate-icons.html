🖨️ Tạo icon PWA từ icon.svg

Trang này vẽ icon.svg lên <canvas> rồi xuất trực tiếp thành 3 file PNG cần cho manifest.json. Đặt file này CÙNG THƯ MỤC với icon.svg, mở bằng trình duyệt (double-click hoặc kéo vào tab), bấm nút bên dưới, 3 file sẽ tự tải về — copy chúng vào cùng thư mục với index.html trên GitHub Pages. Sau đó có thể xoá file này đi.
